MT5 auto-trading

Signals of alerts with MT5 ticked are executed in your MT5 account by the PineAlert EA, immediately at the market price (even if it moved since the signal).

⬇ Download the MT5 EA
How to install the EA
  1. MT5 → Tools → Options → Expert Advisors: tick Allow algorithmic trading and Allow WebRequest for listed URL, add https://pinealert.onrender.com.
  2. File → Open Data Folder → MQL5 → Experts: put PineAlertBridge.mq5 there.
  3. Open it in MetaEditor (F4) and press Compile (F7).
  4. Drag the EA onto any one chart, tick Allow Algo Trading, OK. The key is already filled in.
  5. Keep MT5 open (PC or VPS) — the EA checks for signals every second.
Telegram

The bot token is set in Render → Environment → TELEGRAM_TOKEN.

Message format

Variables: {{emoji}} {{label}} {{name}} {{symbol}} {{exchange}} {{interval}} {{close}} {{open}} {{high}} {{low}} {{value}} {{script}} {{alert}} {{candleTime}} {{sentAt}}. When more than 3 pairs fire together they are sent as one summary message.
